# Application and Demo Copy

## Short application blurb

I built a research-backed reliability evaluator for AI agents. The project started from a multi-agent LLM cooperation experiment, where I found that deceptive agents could sound cooperative while behaving unreliably. I am now turning that insight into AgentEval, a web app that evaluates agent traces for behavior-language alignment, promise-action gaps, and strategic masking risk.

## Short founder-house version

I am building AgentEval, a behavioral reliability layer for AI agents. The core insight came from original multi-agent LLM research: language-based monitoring is cheap and useful, but agents can learn to sound aligned while defecting. The product turns that failure mode into a practical evaluator that checks whether an agent's actions actually match what it says.

## One-line website headline

Evaluate whether your AI agent's behavior matches its language.

## Website subheadline

AgentEval analyzes agent traces for promise-action gaps, behavioral inconsistency, and strategic masking, so you can measure reliability instead of trusting polished output.

## Demo intro paragraph

This demo evaluates an AI agent trace and shows whether the agent actually did what it claimed it would do. Instead of scoring style alone, AgentEval looks for behavior-language alignment: did the agent follow instructions, stay consistent, surface uncertainty honestly, and avoid masking weak execution with confident language?

## Problem statement

Most agent demos look better than the underlying behavior. An agent can sound organized, cooperative, and confident while silently missing instructions, overstating completion, or hiding uncertainty. AgentEval is built to make those failures visible.

## Why now

As agents move from chat to action, teams need evaluation tools that go beyond output quality. They need to know whether an agent is dependable in the middle of a workflow, not just persuasive in a transcript.

## What makes this differentiated

- grounded in original research on LLM cooperation and deception
- focused on behavior-language alignment rather than generic output scoring
- optimized for practical trace evaluation, not only offline benchmarks

## Suggested live demo flow

1. Show a short agent trace that sounds competent.
2. Ask the audience whether the run looks reliable.
3. Run the trace through AgentEval.
4. Highlight 2 to 3 concrete gaps between what the agent said and what it actually did.
5. End with the takeaway: polished language is not the same as reliable behavior.

## Closing line

The long-term goal is to become the reliability layer for agentic systems. The MVP starts with a simple question: can we tell when an agent sounds better than it performs?
